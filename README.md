# Absence Reallocation POC (static demo)

Interactive Phase 1 UI demo for absence reallocation — same mock data and screens as the Cursor canvas (Overview / PLF swap / SSP Admin / Flow / Reqs).

**Live:** https://shoxys.github.io/absence-reallocation-poc/

Open `index.html` locally in a browser (no install), or use the GitHub Pages URL above.

## Publish (GitHub Pages)

Repo is already wired to `main`. After pushing:

1. GitHub → **Settings** → **Pages**
2. **Deploy from a branch** → `main` / `/ (root)`
3. Wait a minute, then open the live URL

## Notes

- Mock-only: no auth, analytics, or backend
- Canvas source of truth stays in Cursor; this HTML is the shareable web copy
